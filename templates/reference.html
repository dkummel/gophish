Feature Reference

Reference for features added to this Gophish installation.

Custom Events

Use this endpoint from a landing page to record a custom action for a recipient.

Endpoint
POST /event
Parameters
rid and action
Action format
1–64 letters, numbers, underscores, or hyphens
Request body
None
Success
204 No Content
Errors
400 invalid action, 404 invalid recipient or completed campaign, 405 wrong method

Every successful call creates a separate Custom Event for an active campaign. It does not change the recipient status.

Landing page snippet

<script>
function trackAction(action) {
    const url = new URL("/event", "{{.BaseURL}}");
    url.searchParams.set("rid", "{{.RId}}");
    url.searchParams.set("action", action);

    return fetch(url, {
        method: "POST",
        keepalive: true
    });
}

trackAction("stage_2");
</script>

Redirect URL placeholders

A landing page redirect URL can include the recipient identifier. It is replaced separately for each recipient.

https://example.com/{{.RId}}/?rid={{.RId}}

Event request details

Event JSON contains the original fields and an additional complete-headers field. It stores the HTTP request line and all request headers. The request body is not included.

Custom events also contain the specific action in details.action.
